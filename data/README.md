# Dataset provenance

`Iris.csv` was provided by the user in an uploaded archive for the CodeAlpha Data Science assignment. The task PDF's dataset link is <https://www.kaggle.com/datasets/saurabh00007/iriscsv>. The supplied CSV, rather than a new network download, is the input used here.

The collection process and redistribution license have not been independently verified. No dataset license is asserted by this repository. The pipeline records the exact input SHA-256 and audit in `outputs/data_audit.json`.
